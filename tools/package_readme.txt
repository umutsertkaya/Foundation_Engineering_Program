GeoTek - kaynak kodlu paket
===========================

GeoTek\GeoTek.exe   Hazir program (klasor surumu). Cift tiklayin; tarayici acilir.
                     Bu klasorun tamamini baska bir bilgisayara kopyalayabilirsiniz.
kaynak\             Programin tum kaynak kodu (Python: geotek, arayuz: web\src, testler, belgeler).
                     web\dist hazir derlenmis arayuzdur.
kaynaktan_calistir.bat  Kaynak koddan calistirir (Python 3.11+ gerekir; ilk seferde paketleri kurar).
                     kaynak\geotek icindeki .py dosyalarini degistirip tekrar calistirabilirsiniz.

Proje dosyalari (.gtk) herhangi bir klasorde tutulabilir: "Konumdan ac" / "Farkli kaydet".
Not: GeoTek.exe derlenmis kodu calistirir; kaynakta yaptiginiz degisiklikler
yalniz kaynaktan_calistir.bat ile gorunur.
