# K1 — yerel başlatıcı ve paket teslimi

Önkoşul: Q1 raporu + **paketleme öncesi kullanıcı onayı**. Bu kart henüz uygulanmadı.
Onay beklerken paket kapsamı ve mevcut araçlar salt okunur incelenebilir.

Küçük teslimler: yerel web başlatıcı → paket tarifi → donmuş uygulama doğrulaması → kullanım belgesi.
Mevcut `pyproject.toml` web/package extras'ı sağlar; henüz `geotek.app` giriş noktası yok.

- FastAPI yalnız 127.0.0.1; derlenmiş web içeriği + pywebview, ağsız kullanım.
- `geotek.modules.*` hidden imports, modül i18n JSON'ları ve yönetmelik YAML'ları pakete girer.
- Donmuş uygulamada `/api/modules` dört mevcut modülü döndürür; `_index.py` yedeği doğrulanır.
- Proje kaydet-aç, test verisi, iş iptali ve sonuçlar paket içinde çalışır.
- `geotek/ui` ancak web eşdeğerliği kanıtlanınca ve geçiş kararı alınca kaldırılır.
- Yeni bağımlılık, başlatıcı ve spec dosyaları ayrı somut kapsamla ele alınır; kullanıcı verisi pakete konmaz.
- Kurulum/kullanım/eksik kaynak açıklamaları README ve kullanıcı belgesine eklenir.

Şef her teslimde tam yazılabilir dosya listesi verir. `check full` paket smoke testinin yerine geçmez.
Üretilen exe açılıp denenmeden dağıtım “tamam” yazılmaz.
